### Ejercicios alternativas II

   1. Escribe un algoritmo que, dado un número del 1 al 7, muestre el nombre correspondiente del día de la semana usando la estructura según.
   1. Realiza un algoritmo que, al recibir una nota del 0 al 10, imprima la calificación textual: "Suspenso", "Aprobado", "Notable" o "Sobresaliente", empleando según.
   1. Crea un algoritmo que reciba un número del 1 al 12 y muestre el nombre del mes correspondiente con la orden según.
   1. Haz un algoritmo donde, según el tipo de usuario introducido (1=Administrador, 2=Invitado, 3=Editor), muestre los permisos asignados.
   1. Desarrolla un algoritmo que, dado el número de una estación (1=Primavera, 2=Verano, 3=Otoño, 4=Invierno), muestre su nombre usando según.
   1. Escribe un algoritmo que pida seleccionar un método de pago (1=Efectivo, 2=Tarjeta, 3=Transferencia) y muestre instrucciones según el método elegido.
   1. Realiza un algoritmo para una calculadora básica: según la opción elegida (1=Suma, 2=Resta, 3=Multiplicación, 4=División), realice la operación entre dos números.
   1. Haz un programa que solicite la edad de una persona y, según su rango (0-12, 13-19, 20-64, 65+), indique si es niño, adolescente, adulto o adulto mayor usando según.
   1. Crea un algoritmo que reciba un código de producto y, según el código (A, B, C, D), muestre la descripción correspondiente.
   1. Escribe un algoritmo que reciba un puntaje de examen y asigne letra de calificación (A, B, C, D, F) según el valor usando la estructura según
   1. Solicita al usuario un valor: si elige 1, calcula el doble del número ingresado; si elige 2, calcula el triple; si elige 3, calcula el cuadrado usando "según".
   1. Pide una opción de conversión: 1 para convertir de centímetros a metros (divide por 100), 2 para pasar de metros a kilómetros (divide por 1000), 3 para convertir de kilómetros a millas (multiplica por 0.621), usando "según".
   1. Solicita al usuario dos números. Según la opción elegida (1=Suma, 2=Resta, 3=Multiplicación, 4=División), realiza la operación entre los dos.
   1. Recibe una opción del usuario: 1 para calcular el área de un círculo (usa πr2πr2), 2 para calcular el perímetro (usa 2πr2πr), 3 para calcular el diámetro (multiplica el radio por 2).
   1. Solicita una nota del 0 al 10. Si elige 1, aumenta la nota en 1 punto; si elige 2, disminuye en 2 puntos; si elige 3, calcula el doble de la nota; si elige 4, muestra la nota sin cambios.
   1. Recibe una opción: 1 para calcular la raíz cuadrada de un número ingresado, 2 para calcular el valor absoluto, 3 para mostrar el número truncado (sin decimales).
   1. Pide el tipo de figura: 1 para triángulo (calcula el área base×altura22base×altura), 2 para cuadrado (calcula el área), 3 para rectángulo (calcula el área).
   1. Solicita una opción: 1 para sumar los números del 1 al N, 2 para multiplicar los números del 1 al N, 3 para restar el primero y último elemento de una serie introducida.
   1. Según el mes (opción 1-12), si es octubre (10), calcula el total a cobrar con un 15% de descuento; para otros meses, cobra el total sin descuento.
   1. Elige la operación a realizar con dos números: 1 para elevar el primero al segundo (potencia), 2 para calcular el logaritmo natural, 3 para calcular el residuo de la división.
